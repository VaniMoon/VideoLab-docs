# Meta App Review Assets for UP REELS

Use these files for Meta Developer app settings.

## Files

- `up-reels-icon-1024.png` - app icon, 1024 x 1024.
- `up-reels-icon-512.png` - app icon, 512 x 512.
- `privacy-policy.html` - public privacy policy page.
- `data-deletion.html` - public data deletion instructions page.
- `privacy-policy.md` and `data-deletion.md` - markdown copies for editing/pasting.

## Suggested Meta App Settings

- App name: `UP REELS`
- Category: `Business` or `Productivity`
- Contact email: `vipgameme@gmail.com`
- Privacy Policy URL: public URL to `privacy-policy.html`
- User Data Deletion URL: public URL to `data-deletion.html`

## Suggested Data Protection Answers

- Responsible entity: use the legal name of the person or company that controls the app and Page data.
- Country: use the country where that person or company operates.
- National security requests in the last 12 months: select `No` if no Meta-sourced personal data was provided to public authorities.
- Public authority request policy: select the options for legal review, objection to unlawful requests, data minimization, and request logging only if you can follow those procedures.
- Processors or service providers with access to Meta Platform Data: select `No` / `None` if Page tokens, Page IDs, user IDs, app secrets, and logs stay only on the user's local computer and are not shared with a cloud provider, contractor, VPS, analytics service, or support vendor. If any outside provider can access those values, list that provider.
