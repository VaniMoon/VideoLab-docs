# UP REELS Privacy Policy

Last updated: May 29, 2026

UP REELS is a private desktop tool for managing and publishing video content to Facebook Pages that the user owns or administers.

## Information We Collect

The application may store the following information locally on the user's computer:

- Facebook Page ID, Page name, and Page access token authorized by the user.
- Video file paths, filenames, captions, hashtags, schedule times, upload status, and publishing history.
- Local thumbnails, rendered video files, watermark settings, and operation logs.

## How We Use Information

We use this information only to connect Facebook Pages, prepare video captions/hashtags/watermarks/schedules, publish videos to selected Pages, and show upload status/history/logs.

## Data Storage

UP REELS stores operational data in a local SQLite database and local project folders on the user's computer. We do not sell user data or share it with third parties, except when the user instructs the application to communicate with Meta/Facebook APIs to publish content.

## Government and Public Authority Requests

We do not voluntarily provide personal data received from Meta to public authorities. If we receive a public authority request, we review its legality, object to unlawful requests where appropriate, disclose only the minimum information legally required, and keep a record of the request and response.

## Data Deletion

Users can request deletion support by emailing `vipgameme@gmail.com`.
