# UP REELS Data Deletion Instructions

Last updated: May 29, 2026

UP REELS is a private desktop application. Most application data is stored locally on the user's computer.

## Delete Data From the Application

1. Open UP REELS / VideoLab on your computer.
2. Go to Settings.
3. Disconnect the Facebook Page account you no longer want to use.
4. Delete local queued jobs, logs, thumbnails, rendered files, and project data if required.

## Request Deletion Support

To request deletion assistance, email `vipgameme@gmail.com` with the subject:

`UP REELS Data Deletion Request`

Include the Facebook Page name or Page ID related to your request.
