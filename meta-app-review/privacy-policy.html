UP REELS Privacy Policy

Last updated: May 29, 2026

UP REELS is a private desktop tool for managing and publishing video content to Facebook Pages that the user owns or administers. This policy explains what information the application uses and how it is handled.

Information We Collect

The application may store the following information locally on the user's computer:

  • Facebook Page ID, Page name, and Page access token authorized by the user.
  • Video file paths, filenames, captions, hashtags, schedule times, upload status, and publishing history.
  • Local thumbnails, rendered video files, watermark settings, and operation logs.

How We Use Information

We use this information only to provide the application's core features:

  • Connecting Facebook Pages selected by the user.
  • Preparing video captions, hashtags, watermarks, and schedules.
  • Uploading and publishing videos to the selected Facebook Pages.
  • Showing upload status, history, and troubleshooting logs.

Data Storage

UP REELS stores operational data in a local SQLite database and local project folders on the user's computer. We do not sell user data and do not share it with third parties, except when the user instructs the application to communicate with Meta/Facebook APIs to publish content.

Government and Public Authority Requests

We do not voluntarily provide personal data received from Meta to public authorities. If we receive a public authority request, we review its legality, object to unlawful requests where appropriate, disclose only the minimum information legally required, and keep a record of the request and response.

Third-Party Services

The application uses Meta/Facebook APIs to authenticate Pages and publish videos. Use of Facebook is subject to Meta's own terms and policies.

Data Retention

Data remains on the user's local computer until the user deletes it, disconnects a Page, removes local project data, or requests deletion support.

Data Deletion

Users can request deletion of locally stored application data by contacting us at vipgameme@gmail.com. Deletion instructions are also available at Data Deletion Instructions.

Contact
