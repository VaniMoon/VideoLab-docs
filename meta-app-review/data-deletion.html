UP REELS Data Deletion Instructions

Last updated: May 29, 2026

UP REELS is a private desktop application. Most application data is stored locally on the user's computer. Users can delete their data using the steps below or request assistance by email.

Delete Data From the Application

  1. Open UP REELS / VideoLab on your computer.
  2. Go to Settings.
  3. Disconnect the Facebook Page account you no longer want to use.
  4. Delete local queued jobs, logs, thumbnails, rendered files, and project data if required.

Manual Local Deletion

If you manage the local project folder directly, remove the local database and generated files from the application's data folder. This may include SQLite database files, thumbnails, rendered videos, logs, and backups.

Request Deletion Support

To request deletion assistance, email vipgameme@gmail.com with the subject: UP REELS Data Deletion Request.

Include the Facebook Page name or Page ID related to your request. We will process deletion requests within a reasonable period and confirm when the request has been handled.
